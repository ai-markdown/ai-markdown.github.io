# AI Markdown website

Publishes https://ai-markdown.github.io/ from the source in [ai-markdown/ai-markdown](https://github.com/ai-markdown/ai-markdown).

The workflow reuses the source repository's Pages workflow to build the homepage, documentation, and embedded Storybook workspace together. Do not copy or edit application source here.

Run **Actions → Organization website → Run workflow** for an immediate update. A scheduled check runs approximately every 15 minutes and rebuilds only when the source commit has changed; GitHub may delay scheduled runs. No cross-repository write credential is required.
